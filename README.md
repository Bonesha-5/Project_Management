## Run in an Emulator

1. Install dependencies:
   ```
   flutter pub get
   ```
2. List available emulators:
   ```
   flutter emulators
   ```
3. Launch one (Android or iOS Simulator):
   ```
   flutter emulators --launch <emulator_id>
   ```
4. Run the app:
   ```
   flutter run
   ```
